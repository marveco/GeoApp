Georeferenced data visualization Tool development. This project aims to explore the potential of relatively small LLMs (7B) for automatic georeferenced data viz, via only natural language requests. The project right now functions in a frontend-backend framework. I'm doing the tests running the heavy part (LLM backend) on a cluster and the app, agents and sandbox environment management (frontend) in my own machine. For this to work, one have to establish the communication tunnel between the backend and frontend machines, also, for table upload and use, one have to place the table in the same folder of the frontend code.
